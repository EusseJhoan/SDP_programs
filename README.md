# SDP programs

## Summary
This repository contains a Jupyter Notebook ([SDP_Bell.ipynb](https://github.com/EusseJhoan/SDP_programs/blob/main/SDP_Bell.ipynb)) that demonstrates how to use semidefinite programming (SDP) to find the maximum quantum violation of the CHSH Bell inequality. This maximum value is famously known as **Tsirelson's bound** ($2\sqrt{2}$).

The notebook uses `cvxpy` to construct and solve the optimization problem.
